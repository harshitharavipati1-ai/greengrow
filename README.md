# 🌱 GreenGrow AI

> **AI-Powered Smart Plant Growth & Sustainable Farming Assistant**

GreenGrow AI is an intelligent agriculture platform that helps farmers and home gardeners grow healthy plants while promoting sustainable farming practices. Using AI-powered image analysis, weather intelligence, and personalized recommendations, the system minimizes excessive fertilizer and water usage while improving plant health.

---

## 🌿 Plant Identification

- Automatically identify the plant
- Detect growth stage

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/greengrow.git
```

Go into the project

```bash
cd greengrow
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build project

```bash
npm run build
```

Run production server

```bash
npm start
```

---

# 🌐 Environment Variables

Create a `.env` file.

```
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
OPENWEATHER_API_KEY=YOUR_OPENWEATHER_API_KEY
PORT=3000
```

Never commit your `.env` file.
